# Seguridad

Este repositorio es una versión pública y no contiene credenciales, llaves de firma, dominios internos ni datos reales.

Si crees haber encontrado un secreto, un dato personal o una vulnerabilidad, **no abras un issue público**:
escribe a leonenriquer201@gmail.com, por LinkedIn al autor ([perfil](https://www.linkedin.com/in/enrique-renteria-le%C3%B3n-71ba393b5)) o usa
*Security → Report a vulnerability* en GitHub.

Valores que siempre deben venir del entorno (nunca del código): `DB_PASSWORD`, `JWT_SECRET` (≥ 32 caracteres), `ROOT_PASSWORD`.
