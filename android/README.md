# android (código privado)

App nativa offline-first: Kotlin · Jetpack Compose · Room · CameraX · WorkManager.

- Los registros se guardan en Room y se sincronizan con WorkManager cuando hay red.
- Rechaza ubicación simulada y se bloquea con opciones de desarrollador activas.
- Captura de foto con CameraX y GPS en el momento del registro.

El código no está publicado. Puedo recorrerlo en una revisión técnica en vivo.
