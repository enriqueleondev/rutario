# backend (código privado)

API REST de Rutario: Java · Spring Boot · PostgreSQL 16 · Flyway.

- Autenticación JWT con `token_version` (sesión revocable) y refresh token para la app Android.
- Seis roles con permisos por ruta y por recurso.
- Fotos de evidencia en disco con purga automática a los 365 días.
- Reportes en Excel y Word.
- Aviso de privacidad versionado, límite de intentos y respaldos cifrados.

El código no está publicado. Puedo recorrerlo en una revisión técnica en vivo.
